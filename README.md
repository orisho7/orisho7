## About Me

I'm a Software Engineering student and backend-focused developer interested in building systems that are **fast, reliable, scalable, and maintainable**.

My main focus is backend engineering, distributed systems, performance optimization, and service architecture. I primarily work with **Go and TypeScript**, while also building applications with Dart and Flutter.

I enjoy taking existing systems and improving their architecture, performance, and reliability rather than simply adding features.

- <img src="https://skillicons.dev/icons?i=go" height="18"/> Backend development with **Go, Node.js, and NestJS**
- <img src="https://skillicons.dev/icons?i=redis" height="18"/> Distributed systems and **event-driven architecture**
- <img src="https://skillicons.dev/icons?i=grpc" height="18"/> **gRPC, REST APIs, Redis, MongoDB, PostgreSQL**
- <img src="https://skillicons.dev/icons?i=docker" height="18"/> Performance optimization, caching, and concurrency
- <img src="https://skillicons.dev/icons?i=linux" height="18"/> Load and resilience testing with **Vegeta and Toxiproxy**
- AI-integrated backend services
- <img src="https://skillicons.dev/icons?i=flutter" height="18"/> Flutter application development
